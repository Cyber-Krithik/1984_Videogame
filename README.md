# 1984: Ministry of Truth Advanced Simulation

A narrative game inspired by George Orwell's *1984*.

## Download

Download a standalone build for your computer (no Python or Pygame required):

- **macOS (Apple silicon):** [Download the app (.zip)](https://github.com/Cyber-Krithik/1984_Videogame/releases/latest/download/1984-Videogame-macos-arm64.zip) — for M1/M2/M3/M4 Macs.
- **Windows:** [Download the game (.exe)](https://github.com/Cyber-Krithik/1984_Videogame/releases/latest/download/1984-Videogame.exe).

### Open on macOS

1. Unzip `1984-Videogame-macos-arm64.zip`.
2. Open `1984-Videogame.app`.
3. If macOS blocks the app because it is not notarized, Control-click it, choose **Open**, then confirm **Open** in the dialog.

The macOS build is for Apple silicon only and is not notarized.
