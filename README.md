# 1984: Ministry of Truth Advanced Simulation

A narrative game inspired by George Orwell's *1984*.

## Download

Get the latest release and choose the download for your computer:

- **macOS (Apple silicon):** [1984-Videogame-macos-arm64.zip](https://github.com/Cyber-Krithik/1984_Videogame/releases/latest) — standalone app for M1/M2/M3/M4 Macs.
- **Windows:** [1984-Videogame.exe](https://github.com/Cyber-Krithik/1984_Videogame/releases/latest) — standalone app.

No Python or Pygame installation is needed.

### Open on macOS

1. Download and unzip `1984-Videogame-macos-arm64.zip`.
2. Open `1984-Videogame.app`.
3. If macOS blocks the app because it is not notarized, Control-click it, choose **Open**, then confirm **Open** in the dialog.

The macOS build is for Apple silicon only and is not notarized.
