# 1984: Ministry of Truth Advanced Simulation

A narrative game inspired by George Orwell's *1984*.

## Play

**[Download the Windows game (.exe)](https://github.com/Cyber-Krithik/1984_Videogame/releases/latest)**

Download the executable from the latest release and open it on Windows to play. The release is packaged as a standalone app; Python and Pygame are not required.
